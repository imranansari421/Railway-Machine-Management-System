# Project Memory & Rules (MEMORY.md)

This document records persistent rules, design choices, and business logic for the Billed Railway Application.

---

## 1. Inbox & Demand Rules (`Inbox.tsx`, `Demand.tsx`)
- **Pending Inbox Display Scope**: Demands generated by the logged-in user must NOT appear in their own Pending Inbox. Pending Inbox strictly displays items forwarded/assigned to the logged-in user or their company admin ("jisko bheja gaya ho").

---

## 2. Issue Voucher & PDF Output Rules (`pdfGenerator.ts`, `Issue.tsx`, `Inbox.tsx`)
- **Issuing Depot / Shop**: Display only the Machine Name or Depot Name cleanly without `SSE/TM/` or `SSE/` prefix (e.g., "BCM-012" instead of "SSE/TM/BCM-012").
- **Consignee & CD Code Cleanup**:
  - Removed redundant `CD CODE` (e.g., `59`) and `(Consignee Code: 074385 / 074380)` text from voucher header and sections.
- **Sub-Depot**: Displays the machine name that demanded the item (`machineName`).
- **ISSUED BY / CONSIGNEE**: Populated dynamically with the issuing employee's name (`issuedBy` / `officerName`).
- **DEPOT / SHOP OFFICIAL**: Displays the issuing employee's name (`officerName` / `issuedBy`) and designation (`officerDesignation`). Removed generic static "SSE/TM" designation label.
- **Seals & Verification Tags**: Removed "Signature Verified ✔" badge from voucher output.

---

## 3. Maintenance Section Rules (`Maintenance.tsx`)
- **Special Characters Restriction**: All maintenance inputs (Machine Name, Company Name, Section Titles, Section Details, Attended By, Search Query) sanitize and strip special characters (`!@#$%^&*+=~`|<>?{}[\]\\;:"]`).
- **ATTENDED BY Input**: Input is strictly converted to **BLOCK LETTERS (UPPERCASE)** both live on keypress and upon form submission.
- **Filter By Employee**: Dropdown in Maintenance Records dynamically aggregates active employees list and report authors, allowing accurate filtering by employee name, email, or employee ID.

---

## 4. Application Architecture & Guidelines
- Built with React 18, Vite, Tailwind CSS, and Firebase Firestore/Auth.
- All code changes must build (`compile_applet`) and pass linting (`lint_applet`) cleanly without errors.

---

## 5. Store Menu & Company Inventory Dispatch (`Store.tsx`)
- **Store Access**: Added "Store" navigation menu for `admin-light` (Company Admin) and `full` access accounts.
- **Company Store Management**: Company admins can add, edit, stock, and manage company items (spares, parts, consumables).
- **Direct Dispatch & Issue Vouchers**: Items can be issued directly from Store to target machines or other companies with automatic stock deduction and PDF Issue Voucher generation.
